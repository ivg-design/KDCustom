# KDCustom icon artwork

The app icon master (`AppIcon-generated.png`) was created with the built-in image generation tool. `scripts/build-icon.swift` packages that unchanged master at the sizes required by macOS into `AppIcon.icns`. The matching 18-point monochrome menu-bar mark is original vector drawing code in the same script, exported as `MenuBarTemplate.png` and `MenuBarTemplate@2x.png`; macOS supplies its appearance tint.

Generation direction: a macOS application icon for KDCustom, a precision dual-dial controller. Dark graphite rounded-square tile, a large concentric machined dial with a dark face and restrained satin-silver outer ring, one amber index near one o'clock, and two small rounded keycaps below. Front-facing, simple silhouette readable at small sizes, soft light from the upper left, graphite and restrained amber palette, no text or vendor logo, transparent outside the tile, no surrounding scene.

The supplied product photograph in `kd-custom.png` remains a separate, unchanged asset. It was not used as or transformed into the application icon.

## Original generation prompt

Use case: logo-brand. Asset type: finished macOS application icon for KDCustom, a precise native creative-tool controller for a dual-dial keypad. Generate one square 1024x1024 polished icon, no text, no lettering, no vendor logo. A restrained graphite macOS rounded-square tile, transparent outside the tile with generous safe padding. Center a bold machined rotary dial: two concentric circular rings with a dark graphite face, satin silver outer edge, one clear small amber index notch near one o'clock. Add a subtle pair of short rounded keycaps tucked below the dial to suggest programmable controls. Strong simple silhouette recognizable at 32 pixels. High-end industrial design, tactile but clean, soft upper-left studio lighting, restrained amber #D89B49 as the only accent, charcoal #191B1D. Front-on orthographic composition, no tilted perspective, no desktop/mockup scene, no external drop shadow, no decorative tiny marks, no gradients outside the tile. Make the dial occupy most of the icon. Actual transparent alpha outside rounded-square tile.
