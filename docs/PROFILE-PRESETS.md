# Initial application profiles

These mappings were installed through the running app's revision-checked MCP configuration service on 2026-09-28. Existing Rive, Huion, and other application bindings were preserved. Key labels use at most seven ASCII characters so the K40's four OLED columns can show each label on one line. The curved buttons retain their existing group navigation action. The physical dial direction and target-app behavior still need live acceptance when the device is connected.

The control numbers refer to the preview with the dials on the left: 1–4 above the screen and 5–8 below. `CW` means clockwise. The inner dial is 1; the outer ring is 2.

| Profile/page | Buttons 1–4 | Buttons 5–8 | Inner CW / CCW | Outer CW / CCW |
| --- | --- | --- | --- | --- |
| General / Browse | Back, Fwd, Pg Up, Pg Dn | Find, NewWin, Close, Sel All | Scroll down/up six lines | Forward/back in history |
| Photoshop / Photo edit | Heal, Clone, Crop, Select | Levels, Curves, DupLay, Undo | Brush size up/down | Zoom in/out |
| Photoshop / Draw | Brush, Eraser, Pick, Swap | Colors, NewLay, Undo, Save | Brush size up/down | Brush hardness up/down |
| After Effects / Timeline | Play, Graph, Keys, Pos | Scale, Rotate, Opacity, Work In | One frame forward/back; physical Shift selects ten frames | Next/previous visible time-ruler item |
| After Effects / Values | Same eight buttons as Timeline | Same eight buttons as Timeline | Value +/−1; physical Command selects 0.1, Shift selects 10 | Same value controls |
| Illustrator / Paths | Select, Direct, Pen, Shape | CmpPath, Release, Join, PScribe | Zoom in/out | Nudge selected artwork right/left |
| Illustrator / Astute | PScribe, Corners, Direct, Pen | Join, Average, CmpPath, Release | Zoom in/out | Nudge selected artwork right/left |

The General profile is the fallback and is useful in Finder and Chrome. Its history keys send Command+[ and Command+], which both applications document for back and forward. Page controls send actual Page Up/Down keys; the inner dial sends line-scroll events. `NewWin`, `Close`, `Find`, and `Sel All` use Command+N/W/F/A. [Apple Finder shortcuts](https://support.apple.com/en-us/102650), [Chrome shortcuts](https://support.google.com/chrome/answer/157179?hl=en).

Photoshop uses the native tool keys J/S/C/W for photo work, B/E/I/X/D for drawing, plus Command+L/M/J/Z, Command+Shift+N, and Command+S. The dials use bracket keys for brush size and Shift+brackets for hardness. Command++ (Command+Shift+= on a US keyboard) / Command+− is used for zoom. These are intended for the installed Photoshop Beta (`com.adobe.Photoshop`); any customized Photoshop shortcut set may differ. [Adobe Photoshop shortcut reference](https://helpx.adobe.com/content/dam/help/en/photoshop/using/default-keyboard-shortcuts/photoshop-keyboard-shortcuts.pdf), [shortcut settings](https://helpx.adobe.com/photoshop/desktop/get-started/settings-and-preferences/view-keyboard-shortcuts.html).

After Effects defaults to Timeline page 1. Command+Left/Right moves the current-time indicator one frame, Command+Shift+Left/Right moves it ten; J/K moves to the previous/next visible time-ruler item; Shift+F3 toggles the Graph Editor; U shows keyframed properties; P/S/R/T show position/scale/rotation/opacity; B sets the work-area beginning. The enabled `ae-numeric-values` rule switches only the dials to Values page 2 when macOS identifies a focused AX numeric control. It does not claim to recognize every AE underlined text value: select page 2 manually if that field is reported as ordinary text. Values use native Up/Down shortcuts; Command selects 0.1 units and Shift selects 10. No typed-value replacement or automatic commit is used. [AE keyboard shortcuts](https://helpx.adobe.com/after-effects/desktop/get-started/keyboard-shortcuts/keyboard-shortcuts-reference.html), [AE property-value increments](https://helpx.adobe.com/after-effects/desktop/work-with-layers/layer-properties/layer-properties.html).

Illustrator Paths uses V/A/P, Shift+M Shape Builder, Command+8 make compound path, Command+Option+Shift+8 release, and Command+J join. Astute PathScribe uses **Shift+A**, verified in Illustrator's live toolbar and its active `v1` shortcut set. Dynamic Corners initially had no shortcut; **Shift+Q** was assigned in that active set, with no conflict shown, and the live toolbar then displayed “Dynamic Corners Tool (Shift+Q)”. Astute page 2 key 2 sends the same shortcut. A private byte-for-byte backup of `v1.kys` was made before saving; comparison showed Dynamic Corners as the only changed existing assignment, though Illustrator rewrote 21 previously absent empty command entries. `Average` sends Command+Option+J. The outer dial nudges a selected object or anchor and can change artwork; only turn it with intended selection. [Illustrator shortcut reference](https://helpx.adobe.com/illustrator/using/default-keyboard-shortcuts.html), [Astute PathScribe](https://docs.astutegraphics.com/vectorscribe/pathscribe-overview), [Astute Dynamic Corners](https://docs.astutegraphics.com/vectorscribe/dynamic-corners).

Verification is separate from configuration readback: check the physical OLED for single-line labels, then exercise each page in a disposable Finder/Chrome view and disposable Adobe documents. In AE, check both a clearly accessible numeric control and an underlined text value; the latter may require manual Values page selection. Confirm that Photoshop and Illustrator use the expected active shortcut sets before editing valuable work.
